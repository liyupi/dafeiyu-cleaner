# 隐私说明 · 大肥鱼消除计划

更新日期：2026-10-23

## 我们收集什么

什么都不收集。插件没有自己的服务器，也不包含任何统计或埋点。

## 插件在你的电脑上保存什么

以下数据只保存在你浏览器的 `chrome.storage.local` 中，卸载插件即删除：

- 设置项（处理方式、严格度、音效开关等）
- DeepSeek API Key（如果你填写了）
- 遣返名单 / 人类白名单（账号 ID、昵称、头像地址、时间）
- 战绩统计
- 前科记忆：在多个页面被认出是大肥鱼的账号 ID、昵称和最近几个页面编号（BV 号），用于下次识别加分，可在设置里清空
- DeepSeek 精判结果缓存：账号 ID、AI 概率和一句判词，保存 7 天，避免重复花费你的 Token
- 你上传的自定义形象图片

## 插件会访问哪些网络地址

| 地址 | 用途 | 时机 |
| --- | --- | --- |
| `api.bilibili.com` | 读取公开的用户资料卡与投稿列表，用于空间主页鉴定 | 打开某个空间主页时 |
| `i0/i1/i2.hdslb.com` | 读取评论者头像，在本地计算颜色特征 | 浏览评论区时 |
| `api.deepseek.com` | DeepSeek 精判 | 仅当你开启精判并填写了自己的 API Key |

开启 DeepSeek 精判后，发送给 DeepSeek 的内容仅限于：可疑账号的昵称、等级、签名、最多 3 条评论正文、离线规则分数；空间鉴定时另含该账号近期投稿标题与头像图片地址。这些内容会受 DeepSeek 自身的隐私政策约束。在 Firefox 中，打开精判开关时浏览器会询问你是否允许发送网页内容，不同意则只使用离线规则。

## 插件不会做什么

- 不读取、不发送你的 Cookie 或登录信息
- 不以你的身份发评论、点赞、举报、拉黑或删除任何内容
- 「赶走」「折叠」「泡泡大炮」都只是修改你本地看到的页面
- 名单导出是在你本机生成 JSON 文件，不会上传到任何地方
